# Template Konten Pembelajaran — Bagian 1–4

Dokumen ini adalah **template isian** untuk konten media pembelajaran interaktif. Isi setiap slot yang bertanda `[ISI: …]`. Setelah dokumen lengkap, developer akan memindahkan isinya ke konfigurasi aplikasi (tanpa mengubah kode program).

> Konvensi: teks dalam tanda kurung siku `[ISI: …]` adalah **tempat isian**. Hapus tanda kurung siku saat mengisi.

---

## Struktur Umum Setiap Bagian

Setiap bagian memiliki urutan langkah berikut:

1. **Halaman awal** — judul bagian + deskripsi singkat + tombol mulai.
2. **Apa yang Akan Kamu Pelajari?** — tujuan pembelajaran + daftar aktivitas.
3. **Materi** — teks materi + media (gambar, grafik, video, simulasi/embed).
4. **Aktivitas** — soal/latihan.
5. **Kesimpulan** — ringkasan + lanjut ke bagian berikutnya.

Khusus **Bagian 3** terdapat tambahan langkah **Diskusi Kelompok** (hasil dibagikan melalui Forum Moodle).

## Catatan

- Jika satu bagian membutuhkan lebih dari satu aktivitas, salin blok "Aktivitas" dan beri nomor.

- Materi, soal, dan feedback akan dimasukkan ke konfigurasi aplikasi tanpa mengubah kode program.
